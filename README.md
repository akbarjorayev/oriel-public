# Oriel

A new wallpaper, every day. Oriel is a free Windows app that sets a fresh, high-quality Unsplash
photo as your desktop wallpaper every day.

**[Download Oriel for Windows](https://github.com/akbarjorayev/oriel-public/releases/latest/download/Oriel-Setup.exe)** · [Website](https://oriel.akbarjon.uz)

This repository hosts Oriel's releases. Installed copies update themselves from here.

Requires Windows 10 (version 2004) or Windows 11, 64-bit. Oriel is in beta: if Windows says it
protected your PC, click **More info**, then **Run anyway**.
